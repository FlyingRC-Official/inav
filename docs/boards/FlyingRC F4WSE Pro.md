# Board - [FlyingRC F4WSE F405 Pro](https://flyingrc-official.github.io/product.html?p=f4wse-pro)

## Specification:

* STM32F405RGT6 CPU, 168 MHz
* ICM42688P or BMI270 IMU
* SPA06-001 barometer
* AT7456E/AT7465E compatible analog OSD
* External TF card module for blackbox logging
* 6 UART serial ports
* I2C
* Built-in SBUS inverter on UART2 RX
* 12 PWM outputs
* Onboard current sensor, 80 A continuous / 120 A instant
* VBAT input range 7-28 V, 2S-6S LiPo
* 5 V 3 A device BEC and 5 V 5 A servo BEC
* Passive buzzer output
* WS2812 LED strip output on S12 when using INAV
* External USB Type-C board
* Dimensions: 22.6 x 42.8 x 9 mm
* Weight: 9.1 g

## Details

* For FlyingRC F4WSE Pro use `FLYINGRCF4WSEPRO` firmware.
* The board supports INAV fixed-wing workflows.
* SBUS is internally connected to UART2 RX.
* The manufacturer manual documents receiver, GPS, telemetry, PWM, USB sub-board, and TF card module wiring.
